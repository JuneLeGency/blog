## 如何写新文章

1. 在 `_posts/` 目录下创建文件，命名格式为 `YYYY-MM-DD-title.md`
2. 开头加上 front matter（layout、title、date 等）
3. 正文使用 Markdown 编写
4. `git commit` 并 `git push` 到 `main` 分支即可发布

```bash
bundle install
bundle exec jekyll serve
```
